# Security Notes

Этот репозиторий специально использует безопасный учебный сервер: он не выполняет shell-команды, не пишет в базы данных и не обращается к внешним API.

Главный принцип:

> **Описание инструмента — не security boundary.**

Если агенту доступен инструмент с опасными полномочиями, ограничения должны существовать на уровне системы, а не только в prompt.

Перед подключением реальных инструментов стоит продумать как минимум:

- минимально необходимые права;
- allowlist разрешённых операций;
- строгую валидацию аргументов;
- разделение read и write возможностей;
- подтверждение человеком для чувствительных действий;
- sandbox / изоляцию исполнения;
- аудит вызовов инструментов;
- защиту секретов и чувствительных данных.

Практические реализации этих идей будут находиться в следующем репозитории learning path: **mcp-secure-agents**.
