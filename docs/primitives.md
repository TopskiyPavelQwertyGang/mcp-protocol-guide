# Tools, Resources и Prompts

Три базовых примитива удобно различать по вопросу: **что именно сервер предоставляет клиенту?**

## Tools — действия

Tool — вызываемая операция.

```text
add(2, 3)
search_cve("CVE-2026-...")
get_package_version("freerdp3")
```

Инструменты особенно важны с точки зрения безопасности, потому что некоторые из них способны менять состояние внешней системы.

## Resources — контекст и данные

Resource предоставляет данные по URI.

```text
package://freerdp3
file://...
git://...
```

В учебном сервере ресурс `package://{name}` возвращает безопасную демонстрационную информацию и не обращается во внешние системы.

## Prompts — переиспользуемые шаблоны

Prompt — именованный шаблон, который помогает клиенту сформировать взаимодействие с моделью.

Например:

```text
analyze_package("freerdp3")
```

может вернуть инструкцию о том, как структурировать анализ пакета.

## Простая ментальная модель

```text
Resources → что модель может получить как контекст
Prompts   → как пользователь/клиент может сформировать запрос
Tools     → что модель может попросить выполнить
```

Это упрощение для обучения, но оно хорошо помогает не смешивать три примитива на старте.
